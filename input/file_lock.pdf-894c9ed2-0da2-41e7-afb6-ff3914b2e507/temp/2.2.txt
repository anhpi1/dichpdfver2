The sharing mechanism uses a file with the same name as the network file with the extension glk. This file
will be referred to a glk file in the following descriptions and the file contains the following information:
• a list of all users who have opened the network file
• a series of records containing the changes made to the file . These records are used to update the indi-
The glk file is created when the first user opens the network file. At this point the file contains the name of
the user and the revision date. The change number is set to zero. The program will then begin to monitor
the glk file at 30 second intervals to determine if the revsion date has changed.
The glk file is deleted when the last user closes the network file.
